# Garment Lab public information site

This folder is a static GitHub Pages site with the home, privacy, terms, and support pages.

## Publish it
1. Create a **public** GitHub repository named `garment-lab-site` (or another name you prefer).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Wait for deployment and use the Pages URL shown in repository settings.
5. Open and test all four pages over HTTPS. Use those exact URLs in the submission dashboard.

GitHub Pages publishing steps: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Before submission, review the policies for accuracy and replace the support email if you want to use another address. The privacy text deliberately does not promise specific OpenAI retention or training behavior.
